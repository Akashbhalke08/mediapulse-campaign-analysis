# MediaPulse Campaign Analytics - Q1 2024

## Project Overview
End-to-end data analysis of PR campaign performance 
across 3 brands and 3 months.

## Tools Used
- Python, Pandas, Matplotlib, Seaborn
- Jupyter Notebook, VS Code

## Key Findings
- 7 data quality issues found and fixed
- Monthly conversions grew 267% (Jan → Mar)
- Crisis campaign: high coverage, zero conversions
- UrbanNest: highest open rate at 42.5%

## Project Structure
- data/raw/ — Original dataset
- notebooks/ — Analysis notebook
- outputs/ — Charts and reports
